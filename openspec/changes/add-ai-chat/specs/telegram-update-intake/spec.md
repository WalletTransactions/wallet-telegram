## MODIFIED Requirements

### Requirement: Маршрутизация сообщений
Бот SHALL направлять сообщение так:
1. `/start` и `/help` — без проверки связки.
2. `/wallets`, `/categories`, `/last`, `/default`, `/tz`, `/unlink`, `/ai`,
   `/new` — только при наличии связки.
3. Текст, начинающийся с цифры или знака `$`, `€`, `₽`, — трата в строгом
   формате.
4. Если задан `WALLET_AI_URL` и есть связка:
   - ответ на уточнение чата (`ai-chat`, «Ответ на уточнение») — вопрос в чат;
   - текст с признаками вопроса (`ai-chat`, «Признаки вопроса») — вопрос в чат;
   - прочий текст с цифрой не длиннее 300 байт — трата свободным текстом.
5. Всё остальное — непонятое.

#### Scenario: Команда чтения без связки
- **WHEN** пользователь без связки отправляет `/wallets`
- **THEN** бот предлагает подключиться через веб-кабинет и не обращается к сервисам кошелька

#### Scenario: Непонятное сообщение
- **WHEN** связанный пользователь пишет «привет»
- **THEN** бот отвечает «Пока не понимаю это сообщение. /help — что я умею.»

#### Scenario: Непонятное сообщение без связки
- **WHEN** пользователь без связки пишет «привет»
- **THEN** бот предлагает подключиться через веб-кабинет

#### Scenario: Вопрос без связки
- **WHEN** пользователь без связки пишет «сколько за няню?»
- **THEN** бот предлагает подключиться через веб-кабинет, wallet-ai не вызывается

#### Scenario: Вопрос без ИИ
- **WHEN** `WALLET_AI_URL` пуст, и связанный пользователь пишет «сколько за няню?»
- **THEN** бот отвечает «Пока не понимаю это сообщение. /help — что я умею.»
